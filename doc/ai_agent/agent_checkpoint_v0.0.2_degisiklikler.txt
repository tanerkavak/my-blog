10. CLI (Bölüm 6)
-----------------
Yeni komutlar:
+ aict log                     : Tüm oturumların birleşik zaman çizelgesi.
+ aict undo [--steps N]        : Son pre-edit'e / N tur geriye kısayol.
+ aict pin / pin --remove      : Sabitleme ve etiket (v1'de pinned vardı ama
                                 komutu yoktu).
+ aict doctor [--fix-stale]    : Kilit, tmp, önbellek, şema sağlığı.
+ aict migrate                 : Şema yükseltme.
+ aict agent install/uninstall : Önizlemeli adaptör kurulumu.
+ aict agent hook <olay>       : Adaptörlerin çağırdığı giriş noktası.
+ aict schema                  : JSON çıktı şemaları.

Yeni seçenekler:
+ checkpoint: --trigger, --allow-empty (sözleşmeye eklendi), --rehash,
  --quiet, --json
+ list: --agent, --trigger
+ diff: --stat, --name-only, --max-lines, --json (agent bağlamını şişirmemek
  için; kesilen çıktı truncated: true)
+ restore: birden fazla --path, --json
+ verify: --worktree
+ init / sessions: --json

Ref sözdizimi:
+ tam id, tekil kısa id, pin etiketi, @last, @last~N,
  <session-id>:<sequence>, @session. Belirsiz eşleşme hata + aday listesi.

+ 6.1 Çıkış kodları tablosu (0–10): kullanım, bulunamadı, bütünlük, güvenlik,
  çakışma, ONAY GEREKLİ (7), kilit, süre bütçesi, kısmi başarısızlık.
  (v1'de yalnız "tutarlı sıfırdan farklı" deniyordu.)
+ 6.2 Makine okunur çıktı: {"schema":"aict.<komut>/v2","ok":...} zarfı, sabit
  error.code dizeleri, stdout yalnız JSON / stderr ilerleme, NO_COLOR ve TTY
  dışı renk kapalı, --quiet.
+ 6.3 Ortam değişkenleri: AICT_ROOT, AICT_SESSION, AICT_ACTOR, AICT_AGENT,
  AICT_NONINTERACTIVE; oturum kimliği öncelik sırası.

12. YENİ: YEREL CLI AGENT ENTEGRASYONU (Bölüm 7A)
-------------------------------------------------
+ 7A.1 Katman modeli: Agent → Adaptör (aict agent hook) → Agent'tan bağımsız
  çekirdek. Yeni agent eklemek çekirdeği değiştirmez.
+ 7A.2 Normalize olaylar: session-start, pre-tool, post-tool, turn-end,
  session-end ve trigger eşlemesi. Bash gibi kabuk araçları varsayılan
  pre_edit_tools içinde. Coalescing: pencere içinde değişikliksiz ardışık
  pre-tool olayı yeni checkpoint üretmez. target_paths yalnız ipucu.
+ 7A.3 Adaptör kurulumu: sürüm/destek tespiti, dry-run, mevcut hook'ları
  koruyarak birleştirme, backups/ yedeği, uninstall yalnız kendi girdisini
  kaldırır. Örnek Claude Code hooks JSON'u (SessionStart / PreToolUse / Stop).
  Hook desteği olmayan agent'lar için: talimat dosyası bloğu ve
  `aict run -- <agent komutu>` sarmalayıcısı.
+ 7A.4 Hook hata/süre politikası: fail-closed / fail-open, süre bütçesi,
  agent'ı asla askıda bırakmama, kısa ve varsayılan olarak sessiz hook çıktısı.
+ 7A.5 Agent bağlamında yıkıcı işlemler: yalnız dry-run + kod 7 + insanın
  çalıştıracağı tam komut; allow_agent_destructive yalnız açık yapılandırmayla;
  okuma komutları agent için serbest.
+ 7A.6 Çoklu agent/oturum: oturum kilidi + proje yazma kilidi; undo'nun başka
  oturumun değişikliğini çakışma olarak göstermesi; değişikliklerin oturuma
  göre etiketlenmesi.

================================================
EK GÜNCELLEME — SOHBET ARŞİVİ (storage/)
================================================
Amaç: Agent sohbetlerinin .agent/.checkpoint/storage/ altında yerel olarak
yedeklenmesi ve her sohbet turunun o turda alınan checkpoint'lere bağlanması.

GİRİŞ VE ÜRÜN TANIMI
+ Girişe sohbet arşivi paragrafı (Bölüm 7B'ye atıf).
+ Bölüm 2'ye 9. senaryo: tur sonu, oturum sonu ve bağlam sıkıştırma öncesi
  sohbet yedeği; aict chat komutları.

PARAMETRELER
+ [SOHBET_ARSIVI]   : açık (varsayılan)
+ [SOHBET_MASKELEME]: mask (varsayılan) / none

KESİN SINIRLAR
+ 15: Agent'ın kendi transcript dosyaları değiştirilmez/taşınmaz/silinmez;
      yalnız okunarak kopyalanır. Sohbet içeriği yalnız storage/ altında;
      manifest, log ve hook çıktısına yazılmaz.
+ 16: Arşiv proje dışına kopyalanmaz, paylaşılmaz, başka agent'ın bağlamına
      kendiliğinden yüklenmez.

KLASÖR YAPISI
+ storage/index.json (türetilebilir)
+ storage/objects/<hash[:2]>/<hash> (transcript parçaları; proje nesne
  deposundan ayrı)
+ storage/chats/<agent>/<agent-session-id>/session.json, snapshots/<n>.json,
  normalized.jsonl (türetilebilir)
+ Sohbet arşivinin doğruluk kaynağı tanımlandı.

config.json
+ chat_archive bloğu: enabled, storage_dir, agents, events (turn-end,
  session-end, pre-compact), redaction, redact_patterns, keep_normalized,
  max_transcript_bytes, failure_policy (fail-open), retention.
+ init arşivin açık olduğunu bildirip bir kez onay ister; onay yoksa
  enabled: false. storage_dir durum klasörü dışına çıkamaz.

MANİFEST
+ chat_ref alanı: agent, agent_session_id, snapshot, turn_index.
  Yalnız kimlik içerir, fingerprint'e dahil değildir, arşiv kapalıysa yazılmaz.

CLI
+ aict chat list / show [--turn] [--raw] / search / for <checkpoint-ref> /
  export --format md|jsonl|raw --out / import / verify / reindex
+ <chat-ref> sözdizimi: <agent>:<oturum>, kısa kimlik, @chat-last,
  <agent>:<oturum>@<snapshot>
+ clean --chats seçeneği.
